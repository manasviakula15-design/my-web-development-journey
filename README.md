A web-based **Bank Account Management System** developed using **Python, Flask, HTML, CSS, and SQLite**. The application provides a simple and user-friendly interface for managing bank account operations and maintaining account-related data.

# 📌 Project Overview

The Bank Account Management System is designed to computerize basic banking operations. It allows users to interact with their bank account through a web interface instead of performing operations manually.

The project demonstrates the practical application of **Python programming, Flask web development, database management, and algorithmic problem-solving concepts**.

## 🎯 Objectives

- To develop a simple and user-friendly banking application.
- To manage customer account information efficiently.
- To perform basic banking transactions.
- To store and retrieve account information using a database.
- To provide a web-based interface using Flask.
- To demonstrate practical implementation of programming and DAA concepts.

## ✨ Features

- 🏦 Bank account management
- 👤 Account information management
- 💰 Balance checking
- 🔄 Transaction handling
- 🗄️ Database-based data storage
- 🌐 Flask-based web interface
- 🎨 Responsive and user-friendly UI
- 📩 User messages and transaction feedback
